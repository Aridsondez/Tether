# Shared Relationship App

## Product Overview

This app is a shared operating system for couples. It helps both partners organize their schedules, goals, finances, dates, locations, preferences, gifts, memories, responsibilities, and future plans in one connected place.

Each partner maintains an individual identity and profile, while the app also creates a shared relationship profile. The system should make it easier to understand each other, plan together, stay accountable, manage spending, and preserve important moments without making the relationship feel monitored or overly structured.

Artificial intelligence is embedded throughout the app. It is not limited to a separate assistant page. Users can speak or type naturally from any section, and the AI can help interpret information, create records, update plans, answer questions, and connect features.

# Embedded AI System

The AI assistant should exist throughout the entire app.

Users should be able to speak or type from any page.

Examples include:

* “Add this restaurant to our date list.”
* “How much have we spent on dates this month?”
* “Can we afford dinner this weekend?”
* “Find a Saturday when we are both free.”
* “Plan a date under $100.”
* “Move my fasting timeline back three days.”
* “Add her exam to the calendar.”
* “Remember that she prefers silver jewelry.”
* “Show gifts she wants under $75.”
* “Create a savings goal for our trip.”
* “What should we focus on this week?”
* “Add this purchase to our date budget.”
* “Find saved restaurants near us that we have not visited.”

The AI should understand the user’s current screen and context.

For example, when used from the map, it should understand saved places and location. When used from the finance section, it should understand budgets, spending, and financial goals.

The AI should be able to:

* Create records
* Update records
* Link records
* Summarize information
* Suggest next steps
* Detect conflicts
* Find shared availability
* Calculate remaining budgets
* Build date plans
* Categorize purchases
* Extract preferences from conversation
* Create reminders
* Surface relevant information

Important actions should require confirmation, especially:

* Making purchases
* Sending messages
* Creating reservations
* Moving shared events
* Changing shared budgets
* Deleting information
* Sharing private information
* Modifying another person’s data

# Calendar and Map Connection

The map and calendar should work as one connected system.

A place saved on the map can become a calendar event. A calendar event with a location should appear on the map.

Example flow:

1. One partner saves a restaurant.
2. The restaurant is marked as a high-priority date location.
3. The app finds a night when both partners are free.
4. The AI checks the available date budget.
5. The AI suggests scheduling the restaurant.
6. The couple confirms the date.
7. The event appears on the shared calendar and map.
8. The app tracks the estimated cost.
9. After the date, the couple can record actual spending, photos, notes, and ratings.

The app can also create a multi-location date route, such as:

* Activity
* Dinner
* Dessert
* Travel home

# Finances and Budgeting

Finances should be a central feature, especially for dates, gifts, trips, shared goals, and recurring expenses.

The app should support both personal and shared financial information without requiring complete bank access.

## Budget Types

Users can create budgets for:

* Monthly dates
* Individual dates
* Gifts
* Trips
* Groceries
* Shared bills
* Entertainment
* Relationship activities
* Savings goals
* Major purchases

Each budget can contain:

* Total budget
* Amount spent
* Amount remaining
* Time period
* Spending limit
* Spending categories
* Responsible partner
* Shared contributions
* Linked transactions
* Linked events
* Linked timelines
* Alerts

The system should clearly show:

* How much has already been spent
* How much remains
* How much can safely be spent
* Upcoming planned spending
* Whether a plan exceeds the budget
* Which categories are using the most money
* How spending compares with previous periods

## Date Budgeting

Each planned date can have:

* Estimated total
* Restaurant estimate
* Activity estimate
* Transportation estimate
* Additional spending allowance
* Actual total
* Who paid
* How the cost was split
* Remaining monthly date budget

Example:

* Monthly date budget: $500
* Already spent: $280
* Remaining: $220
* Proposed date estimate: $140
* Remaining after date: $80

The AI could answer:

* “Can we afford this date?”
* “How much can we spend this weekend?”
* “What dates fit within our remaining budget?”
* “How much did we spend on restaurants this month?”
* “Who has paid more this month?”
* “Can we still afford our trip goal?”

## Contributions and Splitting

Shared expenses can be divided by:

* Equal split
* Percentage
* Specific amount
* One partner pays
* Alternating payments
* Custom agreement

The app should avoid turning contributions into a competitive score unless both partners explicitly enable that view.

## Financial Privacy

Users should control whether financial data is:

* Private
* Shared as a total only
* Shared by category
* Fully shared
* Hidden until a specific date

For the first version, manual expense tracking is safer and simpler than direct bank connections.

Users should be able to:

* Disconnect accounts
* Pause sharing
* Export personal data
* Export shared data
* Delete personal information
* Keep private memories
* Decide what happens to shared memories

* Remove location access
* Revoke permissions

Shared data should not automatically become the property of one partner.

# Connected Data Model

The app should be built around connected objects rather than isolated features.

For example, a restaurant can be:

* Saved on the map
* Added to a date plan
* Scheduled on the calendar
* Assigned a budget
* Included in a memory
* Rated after visiting
* Recommended again by the AI

A trip can be:

* A shared timeline
* A calendar event
* A savings goal
* A budget
* A map collection
* A task list
* A memory collection

This connected structure is one of the product’s strongest advantages.

# Main Product Principle

The app should help couples remember, plan, understand, support, and enjoy each other.

The features should not operate as separate tools. Calendars, timelines, places, finances, dates, profiles, wishlists, and memories should continuously inform one another.

The AI layer should connect the system and reduce effort, while privacy controls ensure that each partner maintains personal autonomy.
