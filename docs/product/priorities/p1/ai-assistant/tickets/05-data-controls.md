# AI-5: AI data controls & opt-out

**Epic:** [AI Assistant](../epic.md)

## Description

Baseline transparency and control given the assistant reads relationship and partner data.

## Requirements

- A settings toggle to disable AI features entirely.
- User-facing copy explaining what data the assistant can see, matching whatever context AI-1's calls actually include.

## Acceptance Criteria

- [ ] A user can opt out of AI features from Settings, and doing so actually prevents those API calls from firing.
- [ ] In-app copy accurately describes what data is sent to the AI provider.
