# AI-4: Assistant chat surface

**Epic:** [AI Assistant](../epic.md)

## Description

A real, discoverable entry point for interacting with the assistant — without this, AI-2 and AI-3 have no way for a user to reach them.

## Requirements

- Simple v1: a dedicated screen/sheet (placement — under More, or a new tab — deferred to whoever owns navigation/IA at implementation time) with a chat-style input that routes to the AI-2/AI-3 flows based on intent, or a simpler menu ("Tell me about your partner" / "Describe a goal") if intent-routing is too much for v1.

## Acceptance Criteria

- [ ] A user can reach the assistant from a stable, documented place in the app.
- [ ] The assistant supports at minimum the AI-2 and AI-3 flows.
