# PROFILE-4: "About [Partner]" visual rework

**Epic:** [Partner Profile Revamp](../epic.md)

## Description

A visual, categorized presentation of `partner_notes` to browse structured info about your partner, replacing the current list-based `apps/mobile/src/app/more/partner.tsx`.

## Requirements

- Grouped by category from PROFILE-1's schema, visually distinguished (icons/sections), not a flat scroll list.

## Acceptance Criteria

- [ ] Categories are visually distinct and scannable.
- [ ] Editing/adding an entry from this screen still uses the existing sheet-based edit pattern (`partner.tsx`'s current add/edit flow), just targeting the new schema.
