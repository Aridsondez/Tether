# DATA-5: Settings UI

**Epic:** [Data Export & Deletion](../epic.md)

## Description

Entry points for both actions under More/Settings.

## Requirements

- Export: a straightforward action that produces a file the user can retrieve (e.g. share sheet or emailed link).
- Delete: requires explicit, deliberate confirmation (e.g. typed confirmation or a two-step confirm), with copy stating the real consequence per the DATA-2 policy — not generic boilerplate.

## Acceptance Criteria

- [ ] Export is reachable and produces a file/share sheet the user can actually retrieve.
- [ ] Delete requires deliberate confirmation and clearly states what happens to shared data before the user commits.
